# Security policy

## Supported version

Security corrections apply to the current `main` branch.

## Reporting a vulnerability

Do not publish passwords, tokens, private keys, personal data or a security
vulnerability in a public issue. After publication, use GitHub's private
vulnerability reporting feature in the repository's **Security** tab.

If private reporting is not yet enabled, contact the author through the public
author information associated with the related Zenodo record:
https://doi.org/10.5281/zenodo.19897230

## Research code notice

This repository is a research archive. It is not intended for safety-critical,
medical, financial or production security applications without independent
review and validation.
